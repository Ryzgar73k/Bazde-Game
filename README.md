Hevaller Nasıl Açacak? (Onlara İletebileceğiniz Adımlar)
Projeyi GitHub'dan indirsinler (yeşil Code > Download ZIP diyerek veya git clone https://github.com/Ryzgar73k/Bazde-Game.git yaparak).
Unity Hub uygulamasını açıp Add > Add project from disk desinler ve indirdikleri klasörü seçsinler.
Unity sürümü olarak projenin yapıldığı sürümü (Unity 6000.6.x / Unity 6) seçip projeyi açsınlar.
İlk açılışta Unity 2-3 dakika kütüphaneyi derler. Açıldıktan sonra Assets/Scenes/SampleScene.unity sahnesine çift tıkladıklarında sizin yaptığınız parkur, karakter, kontroller ve dönen engeller birebir karşılarına gelecektir.
